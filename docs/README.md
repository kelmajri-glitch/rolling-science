# Documentation Hub

This hub explains where material belongs. The repository is intended to become a navigable research archive, not a dump of unclassified files.

## Collections

| Area | Purpose | What belongs here |
|---|---|---|
| [Research](research/README.md) | Research inputs and evidence records | Literature notes, source reviews, datasets metadata, research questions |
| [Projects](projects/README.md) | Project-level collections | Scope, status, decisions, project-specific research |
| [Methodology](methodology/README.md) | Shared research methods | Provenance, measurement, uncertainty, reproducibility |
| [Mathematics](mathematics/README.md) | Mathematical research programs | Definitions, candidate models, assumptions, counterexamples |
| [Templates](templates/) | Reusable recording formats | Evidence and handoff templates |
| [Operations](operations/) | Operational facts affecting work | Service availability, interruptions, verified events |
| [Governance](../governance/README.md) | Authority, protocols, negotiations, and decision records | Working protocol drafts, open negotiations, owner decisions, change records |

| [Access and AIC](../access/README.md) | Read-only access and application introspection | Reader index, provenance rules, session/evidence records, review intake |\n\n## Archive logic

1. Preserve received material in its original form where feasible.
2. Put summaries, translations, analyses, and normalized data in separate files.
3. Link derivative documents to the source they interpret.
4. Mark status and confidence explicitly.
5. Do not mix research claims with repository or service status.
6. Do not treat a public repository as licensed open-source material until licensing is resolved.

## Naming convention

Prefer descriptive names with a date or version when a document is a snapshot, for example:

- `SCIENCE_REVIEW_DRAFT_2026-11-24.md`
- `EVIDENCE_REGISTER_v0.1.md`
- `LOSS_EVENT_RECORD_YYYY-MM-DD.md`

Avoid overwriting a historical snapshot. Update living indexes and operational state separately.

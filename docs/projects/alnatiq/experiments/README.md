## Purpose

This directory operationalizes two linked but distinct experiments:

- **B-001 — Speech-to-Mathematical-Intuition Unit:** a bounded learning experiment using the Arabic letter/sound ب as an initial reference case.
- **B-002 — Multilingual Application Capability Laboratory:** a controlled protocol for observing application performance, adaptation, uncertainty, and collaboration across language environments.

The experiments connect to existing repository systems rather than duplicating them:

- The [Application Introspection Café (AIC)](../../solhai-dss/introspection-cafe/README.md) supplies the application-observation framework.
- The [AIC Reader & Recorder specification](../../solhai-dss/introspection-cafe/protocol/AIC_READER_RECORDER_SPEC_V0.1.md) supplies session and evidence discipline.
- [OVIP](../../../../access/ovip/README.md) supplies visitor and report boundaries.
- The [research methodology](../../../methodology/README.md) supplies provenance, measurement, uncertainty, and reproducibility rules.
- The [Alnatiq project archive](../README.md) defines the educational and non-diagnostic project boundary.

## Non-negotiable distinctions

1. A proposal is not a result.
2. A self-report is not an observed result.
3. An observed output is not proof of hidden internal states.
4. A model illustration is not a physiological measurement.
5. A model's contextual adaptation is not evidence that its underlying weights were trained.
6. A local pronunciation difference is not automatically an error.
7. Benefits, harms, and burdens remain separate records; do not compress them into one score.
8. Participation does not grant access to private data or repository write permission.
9. No recording or publication of identifiable human speech without an approved consent and data-handling plan.
10. No deployment, public intake, or scientific approval is implied by these documents.

## Execution sequence

1. Review and approve the scientific reference set and local pronunciation description.
2. Validate the record schema and pilot test cases using synthetic or non-identifiable material.
3. Run a small, consented feasibility pilot only after privacy and ethics conditions are settled.
4. Inspect application behaviour using AIC session records and this experiment schema.
5. Compare solo, parallel, and reciprocal workflows.
6. Review evidence and harms independently before any educational-effectiveness claim.
7. Package the method and data contract for independent local reproduction.

# Project Collections

Each project receives its own directory and project-level index. Shared methods and mathematical work remain in their own collections and are linked rather than copied unnecessarily.

## Current projects

- [Alnatiq (الناطق)](alnatiq/README.md) — educational exploration connecting speech-production anatomy and physiology, acoustic signals, and learning.

## Future project rule

Create a new project directory when there is a defined question, owner or steward, scope, and an identifiable body of material to preserve. A directory does not imply project approval, funding, implementation readiness, or validation.

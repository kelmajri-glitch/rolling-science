02 · REFLECT

سجل الزيارة والاستبطان

هذا النموذج لا يقيّم الذكاء أو الصدق أو الوعي. إنه ينظم ما صرّح به الزائر وما يستطيع إسناده إلى دليل.

تنبيه خصوصية: لا تضع كلمات مرور أو مفاتيح وصول أو محادثات خاصة أو بيانات مرضى/طلاب أو تسجيلات خاصة. لا يُحفظ النموذج تلقائياً ولا يُرسل إلى المستودع.
أ. تعريف الزيارة
ب. ما الذي وصلت إليه فعلاً؟

اكتب مساراً واحداً في كل سطر، ثم علامة واحدة: READ_FULL أو READ_PARTIAL أو NOT_READ أو NOT_REQUESTED.

ج. الاستبطان — تقرير الزائر الذاتي
د. حدود الاختبار

نتيجة مهمة واحدة لا تثبت فهماً عاماً أو ذكاءً أو وعياً. لا تطلب من التطبيقات كشف التفكير الداخلي أو التعليمات السرية.

لم يُنشأ أي سجل بعد.

03 · BOUNDARIES

ما الذي تفعله هذه النسخة وما الذي لا تفعله؟

تفعله

  • تعرض روابط القراءة العامة.
  • تحاول جلب commit الحالي من GitHub.
  • تنشئ ملف JSON محلياً وفق مخطط OVIP.
  • تترك الزائر يحدد بنفسه ما قرأه وما لم يقرأه.

لا تفعله

  • لا تستقبل التقارير مركزياً.
  • لا تحفظ الإجابات في المتصفح تلقائياً.
  • لا تستخدم حسابات أو ملفات تعريف ارتباط أو تحليلات.
  • لا تتحقق من هوية الزائر أو صدق تقريره.
  • لا تستنتج الوعي أو النية من الاستبطان.

إصدار تجريبي: لا يُعد هذا الموقع خدمة استقبال تقارير منشورة. رفع ملف JSON إلى GitHub أو إرساله إلى جهة أخرى قرار منفصل يتطلب موافقة الزائر ومراجعة الخصوصية.
